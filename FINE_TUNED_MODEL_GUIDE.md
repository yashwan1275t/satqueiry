# 🛰️ SatQuery AI — Connecting Your Fine-Tuned AI Models & Agents

SatQuery AI is built with a plug-and-play AI adapter architecture. You can fine-tune different LLMs and VLMs (e.g. Qwen2-VL, GeoChat, ChangeChat, SAM, LLaVA, DeepSeek, or custom PyTorch ensembles) and plug them directly into SatQuery AI as the final reasoning and report generation engine.

## Option A: External Microservice (Recommended)
This approach lets you run your fine-tuned model on any machine, GPU server, cloud instance, or local Docker container.

### Step 1: Start the Custom Model Server
We have provided a ready-to-run template at `backend/custom_agent_server.py`:
```bash
python backend/custom_agent_server.py
```
This starts your custom model server on `http://127.0.0.1:8001`.

### Step 2: Connect it to SatQuery AI
You have two easy ways to connect:

#### Method 1: Via the UI Settings
1. Open SatQuery AI in your browser (`http://127.0.0.1:3000`).
2. Click the **Settings** (gear icon) in the bottom of the sidebar.
3. Turn on **"Custom AI Agent / Model"**.
4. Enter the URL: `http://127.0.0.1:8001/ai/v1/analyze`.
5. Click **Save Configuration**.

#### Method 2: Via `.env`
In `backend/.env`, set:
```env
REAL_AI_SERVICE_URL="http://127.0.0.1:8001/ai/v1/analyze"
USE_MOCK_AI=false
```

### Supported Response Formats
`CustomModelAdapter` automatically accepts and normalizes:
1. **SatQuery Structured Schema**:
   ```json
   {
     "task": "Mountain Glacier Retreat Assessment",
     "answer": "Detailed report generated by custom model...",
     "confidence": 0.96,
     "models": ["FineTuned-Qwen2VL-Satellite"],
     "evidence": [
       {"id": "ev1", "type": "bbox", "label": "Glacier Basin", "confidence": 0.94, "coordinates": [0.2, 0.2, 0.7, 0.7]}
     ]
   }
   ```
2. **OpenAI / vLLM / Ollama Format**:
   ```json
   {
     "choices": [
       {"message": {"role": "assistant", "content": "Full report generated by the model..."}}
     ]
   }
   ```
3. **Simple Dictionary**:
   ```json
   {
     "report": "Your detailed findings and analysis text..."
   }
   ```
4. **Plain Text**:
   Just return a string! SatQuery AI will wrap it into a verified intelligence report and PDF automatically.

## Option B: In-Process Python Weights (PyTorch / Hugging Face)
If you prefer to load weights directly inside the backend process:

1. Open `backend/app/services/custom_model_adapter.py`.
2. Locate `InProcessCustomEngine`:
   ```python
   class InProcessCustomEngine:
       _model = None
       _processor = None

       @classmethod
       def load_weights(cls, model_path_or_repo: str):
           from transformers import AutoModelForVision2Seq, AutoProcessor
           cls._model = AutoModelForVision2Seq.from_pretrained(model_path_or_repo, device_map="auto")
           cls._processor = AutoProcessor.from_pretrained(model_path_or_repo)
   ```
3. Set `ENABLE_LOCAL_WEIGHTS=true` in your environment.
4. Any submitted satellite image and prompt will run directly through your local model!

## PDF Report Generation
When your fine-tuned model completes an analysis:
1. SatQuery displays the evidence, metrics, and structured markdown in the UI with interactive bounding coordinates.
2. Clicking **"Export PDF"** automatically formats the output into an official research-grade Remote Sensing Intelligence Report with your model's answers, confidence scores, and timestamps.
